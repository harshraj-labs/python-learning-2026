Today I learned about: Variables, Datatypes, Comments, Variables naming conventions.
# Variable:
- Variables are like classified/named containers to store data
- To create a variable in python you only to use an assignment operator "=" to assign a value to any word/letter (we don't need to declare datatypes before hand like in C "int","float",etc), following the right naming rules which are: 
            - The variable name must not start with a number
            - The variable name can only start with a letter or an underscore
            - The variable name should be alphanumeric (a-z, A-Z,0-9) and underscore(_)
            - Variables are case-sensitive
- Some naming conventions are:
    - using proper names instead of short forms or single letter to show purpose, useful when working in teams or for your futureself.
    - so instead of "ua = 9", use "user_age = 9"
# Comments: ("#")
- serves the same purpose as in C
- It's used to type smth that the compiler must ignore, usually for communicating and explaing the code
- the compiler ignores everything after the pound symbol ("#")
