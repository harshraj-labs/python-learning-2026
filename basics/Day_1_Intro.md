Knowing the basics of python and where it is used and also how it is installed.
1. Python is used in various fields like data analysis(pandas,numpy), webdevelopment back-end (fastAPI,Flask, Django), also used in microcomputers like raspberry Pi, it's widely used in DevOps. Its biggest strength is in automation.
2. Installation:
    - going to python.org
    - installing the python3 installer.exe
    - installing it using the package installer while making sure to check the box of "add to path"
    - checking the version with cmd "python --version"
